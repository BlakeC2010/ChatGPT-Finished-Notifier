AI Chat Notifications · v1.3.2

Supported AI chats

ChatGPT, Claude, and Gemini.

No notification appears

First check whether the AI chat tab was actually hidden when the response finished. The extension intentionally stays quiet while that tab is still visible, including on another monitor.

If you use System mode, make sure Chrome notifications are enabled in your operating system. On Windows 11, also check Settings → System → Notifications → Do not disturb.

The custom browser toast does not appear

Open the extension's options page and confirm that the notification mode is set to Auto or Browser Toast.

The extension stopped detecting responses

Refresh the affected AI chat tab after updating or reinstalling the extension. If one provider changes its website controls, detection for that provider may need an update.

Service worker says “Inactive”

That is normal for Manifest V3 Chrome extensions. Chrome suspends extension service workers while they are idle and wakes them when needed.

Report a bug

If a supported site stops working, open a GitHub issue and name the site, notification mode, operating system, and what happened. Do not include private conversation content.
