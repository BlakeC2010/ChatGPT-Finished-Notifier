Privacy policy

Simple by design.

Last updated: October 3, 2026

Short version: AI Chat Notifications does not collect, sell, transmit, or analyze your prompts, responses, or browsing history. It runs locally and only stores your notification preference through Chrome extension storage.

What the extension does

AI Chat Notifications runs on supported AI chat websites to detect when a response starts and finishes. When the relevant tab is hidden, it can show an in-page notification on the website you are currently viewing or a system notification.

Website access

Response detection runs only on chatgpt.com, claude.ai, and gemini.google.com. A separate lightweight overlay script is available on normal HTTP and HTTPS pages so the extension can display a notification inside the webpage you are currently viewing. That overlay script does not read, collect, or transmit page content.

Data collection

The extension does not collect or store prompts, responses, conversation history, browsing history outside supported sites, account information, analytics identifiers, or advertising data.

Data stored by the extension

The extension stores your selected notification mode using Chrome's extension storage API. If Chrome Sync is enabled, Google may sync that preference according to your Chrome settings.

Network requests and external servers

The extension does not operate a backend server and does not send your AI conversation content to any external service. Its notification logic runs locally in Chrome.

Permissions

  • Notifications: used to show native system notifications.
  • Storage: used to remember your notification-mode preference.
  • Supported AI chat sites: used to observe interface state so the extension can determine when a response finishes.
  • Website access: used only to place the in-page notification overlay on the active webpage. The overlay does not inspect or transmit the page's contents.

Third parties

AI Chat Notifications is independent and is not affiliated with or endorsed by OpenAI, Anthropic, or Google.

Contact and questions

For privacy questions or issues, use the project's public GitHub repository and support page.
